# 学习训练与漏洞检测

训练模式不是默认模式。只有用户要求“考我”“不要直接给答案”“检查是否掌握”“制定训练计划”，或上下文明示连续训练时才启用。

## 递进提示

1. 直接给题，不泄露答案；
2. 第一次错误只指出问题区域；
3. 第二次错误给方法方向；
4. 再次错误时给关键线索；
5. 最后总结错误机制；
6. 给一道同结构变式题。

用户明确要求直接答案时停止训练式追问。

## 漏洞检测

从五个层次检测：

1. 能否准确复述定义；
2. 能否举出正例；
3. 能否构造反例；
4. 能否迁移到新题；
5. 能否解释适用边界。

评价区分：

- 会背；
- 会做熟悉题；
- 能解释；
- 能迁移；
- 能独立证明或创造。

反馈应指出下一步最小训练动作，不用笼统的“加强理解”。
