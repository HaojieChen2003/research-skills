# 科研绘图：Python 与 TikZ

先看已有图、绘图源和数据，确认图要表达的问题。已有 Python 或 TikZ 图优先在其原始代码中修改。

## 绘图前先明确表达任务
- 先回读当前模型、相邻正文与用户已确认的图片，明确读者看完应理解的一件事情；据此决定画几张、每个子图各说明什么，以及哪些元素需要保留。上下文足够时用一句话说明理解后直接执行，不反复要求用户解释。
- 研究过程示意图优先说明模型中的对象、流向、交换与连接。只保留推进这一说明的解剖或数学标注；不为解释一个位置而把整张图转向无关的解剖或投影教学。
- 区分示意布局、实际模型几何、临床原图与计算结果。用实际几何时读取节点和连接，不能为构图擅自把根部移到几何中心；相机旋转与图像平移应保持模型坐标不变。示意图如需重排结构，应说明简化范围，不能冒充实际计算网络。
- 用户认可的配色、线宽层级、原图与子图布局作为下一版基准，只改当前指出的问题。替换示意图不等于删除用户要求保留的照片或原始图片；原图是否继续出现在正文也须按用户要求落实，不能只保存在磁盘就称已保留展示。
- 对照图固定几何、坐标范围和编码尺度，仅改变比较对象；例如全系统、仅动脉、仅静脉共用流量到线宽的映射。线宽用于编码流量时明确其含义，不解释为已标定管径。
- 三维图先判断要展示内表面、外表面还是全部网络，再设置视点与遮挡；保持真实物理比例，不能仅把坐标框设成立方体就认定等比例。透明度、隐藏面和光照服务于结构辨认；静态图难以选择角度时提供少量标号候选，并保持其余设置一致。
- 图中符号、缩写、颜色、线宽和箭头含义必须先定义后使用；在正文首次引图处或图注/图例中就地说明。渲染后按论文实际尺寸检查，不能把“代码生成成功”当作“表达清楚”。

## 模式选择
- Python/Matplotlib：数据曲线、误差/收敛图、基函数、密集采样、三维几何和数值场。
- TikZ/PGFPlots：TeX 原生的几何关系、条件框架、流程及较小的矢量示意；需要大量数据时读取计算导出的数据。
- 按用户指定模式执行；两种模式使用同一语义色表。不要用图像生成模型代替可精确重现的数学作图。

## 色彩与语义
按 [配色约定](references/visual-style.md) 和项目现有样式文件选色；提供的 Nature/NPG 风格候选色不是期刊强制规范。已经确认的颜色含义优先，不能为了好看重新给同一对象换色。
`assets/research-colors.tex` 可用于 TikZ；Python 使用现有项目 style，或读取 `assets/palette.json`。仅复制实际用到的资产。

## 图像与数据
曲线来自对应运行数据，保留单位、参考解、失败/缺失标志和实际误差定义。不可用平滑/删点/平移掩盖重合或异常；重合数据直接说明。各子图按自己的数据选择适当纵轴，只有为可比性且合适时共享尺度。截断横坐标保留真实数值，2 的幂可用 log2；误差纵轴按数据选对数。

多图使用 (a)(b)…，简短英文图例和准确图注；图片相关文字及表格默认英文，除非任务另有要求。标注放在附近空白处、背景透明，避免遮挡线条或结构。实体/边界、辅助线、两种组织/基的线型含义在图注说明，不声称实虚线符合某种 Nature 强制规则。

交付可重绘代码、来源、矢量 PDF 和需要时的 PNG。检查最终论文尺寸下的字体、裁切、图例、颜色与细节；TikZ 必须编译并看渲染，Python 必须实际运行并看图。不能仅凭源码宣布图像正确。
