# 配色与两种绘图模式

优先读取当前项目现有样式和用户已经确认的对象映射。全局资产提供 NPG 风格候选色，并不表示 Nature 的强制配色标准。

候选色：blue #3C5488；coral #E64B35；teal #00A087；purple #8491B4；ink #202020；gray #6B7280。

项目已有样式文件优先：按项目实际目录查找并核对，不使用其他机器的路径或历史配色核查作为当前事实。两组基及动静脉的颜色映射沿用用户已认可的当前图。

每次绘图应固定本图组内的“颜色→基/对象”和“线型→组织/边界”等映射，避免一个颜色同时承担冲突含义。需要第二种区别时使用线型或标记，不重新随机分配颜色。不同论文可以有不同映射，项目映射优先。

Python 和 TikZ 使用相同 hex。TikZ 资产以 ResearchBlue 等名字定义 xcolor 颜色；不要重复定义项目现有同名颜色。Python 默认复用项目 style，资产 JSON 用于没有现有样式的新项目。

三维图中的坐标文字放在就近空白、透明底；投影图对应边界和半径的线型须对应。误差多图布局由任务决定，不把过去的 2×4 布局变成所有图的强制条件；各图纵轴按自身误差范围设置。
