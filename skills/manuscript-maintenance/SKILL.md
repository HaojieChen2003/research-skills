# 论文与参考文献维护

读取实际主文稿及项目指导，保持当前编辑文档与用户范围。英文改英文、中文改中文；标题/图表按项目约定。数学推导结合 pde-model-audit；数值结果结合 numerical-experiment；图像结合 research-figures；PDF 视觉检查使用可用 PDF 工具。

1. **先定义后使用是首要写作与审查原则。** 适用于正文、公式、推导、图表、图注及口头解释：区域与测度、已知/未知量、变量与指标集、物理量与单位、参数、空间、算子、缩写和误差指标，都必须在首次使用前或引入它的同一句/公式中定义。定义说明“是什么、在哪个域或范围、物理/数学含义”，不能只写“某某系数”或“见文献”。派生量同时说明与原量的关系及引入用途。
   编辑前按首次出现位置核对依赖关系；搬动段落、公式或附录后重新检查，避免把定义移走却留下前面的使用。共享定义可在紧邻段落集中给出；独立阅读的图表与周报应就地解释关键符号。未确定的定义明确标待核定，不凭猜测补写。
2. 按专业审稿方式检查“定义—条件—推导—结论”的依赖，数学命题转 pde-model-audit 的审稿与 Lean 流程；指出具体缺少的条件、引理和证据，不用笼统评价。核对 Lean 命题是否匹配论文，不以编译或定理数量代替全文证明。
   确认各节推进的论证，合并重复内容；保留影响结论的条件，删去仅为预防质疑的文字。实验里区分已执行方法、候选框架和失败记录。
   引言按“研究对象与现象—已有工作—具体未解问题—本研究问题与证据”核查；数学自洽或 Lean 通过不替代研究动机。区分文献明确提出的限制与作者自己的比较推断，不能从一次检索未发现论文推断研究空白。
   回答“正在算什么方程”时先给本轮实际方程、未知量与条件；回答参数取值时直接给值、单位和派生关系。不把完整模型、当前简化实验和未来计划混写。用户只要紧凑汇报时，按方程、参数、结果、下一实验组织，不增加无关背景。
3. 方程、参数、数据和图表必须对应同一实验。明确算术精度、参考解、截断、时间法、求积、范数与 EOC。无效/未计算数据不填入成功结果。
4. 文献检索、相关工作综合与动机证据调用 research-literature-synthesis；原文获取调用 research-literature-access。逐条建立“引用位置—支持的主张—原文依据”。引用跟随具体论述，核对作者、年份、DOI/出版状态；无法确认的手稿不伪造作者或发表信息。借鉴与证明分开。
5. 当前文献表仅列实际引用条目。删除共享 Bib 条目前检查其他主文稿是否使用；必要时为本文生成专用 Bib，保留其他文章的数据。
   编辑外部或旧稿前读取实际原文和目标范围；结构性LaTeX修改使用括号感知扫描/解析或人工限定片段，不用跨嵌套参数的宽泛正则。简单字面替换仍可用。改前保留版本或任务备份，改后查看diff、统计预期替换数并核对每个结构性改动，不能因替换数吻合就认定语义正确。
6. 按用户已选样式处理公式断行、章节编号、竖版、表题在上且居中、浮动体尺寸和图注。不要把一般美术偏好写成期刊强制要求。
7. 编辑后调用可用内置编译工具，修复源错误；环境失败与源错误分开，可使用项目构建脚本验证。比较改前后的Overfull/Underfull、未定义引用等日志数量和具体位置，再渲染检查更改页面及受影响的交叉引用；告警计数为线索，不以零告警代替视觉验收。保留原编辑器。

交付保存后的源与 PDF、实质修改和仍未解决的问题。编译成功只证明排版构建通过，不代替数学和数据验证。
