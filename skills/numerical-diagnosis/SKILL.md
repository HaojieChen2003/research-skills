# 数值异常分层诊断

先明确异常现象和判据，保留原配置与失败输出，用小规模可复现例定位。

按与现象相关的阶段取证：方程/单位/条件 → 已知输入 → 基及导数 → 求积 → 矩阵/载荷 → 线性求解或时间推进 → 重构场 → 误差积分。为阶段之间保存可比数据，避免只查看最后的误差曲线。

- 积分：区分数学发散、可积奇异性、求积未分辨与浮点消去。有限求积和不能证明原积分收敛。复合/局部加密先检验常数积分、权重测度、区域覆盖及重叠；几何面积与带Jacobian曲面面积分别核对。构造应精确保常数的分区规则按舍入误差验收，普通规则报告权重和的积分误差并加密核验；不能强制归一化掩盖漏区/重叠。该误差须纳入目标误差预算。
- 相减量：A-B或(A-B)/B很小时，同时报告A、B、带符号差、归一化差及各自加密变化，检查浮点消去和积分误差的相消。差很小不能反推A、B已分别收敛；接近舍入/积分噪声的差值不用于可靠EOC。涉及谱项或交换正负部时同样适用。
- 收敛归因：实测EOC须说明参考依据和加密比，先判是否进入渐近区再外推，不套用方法名义阶。某参数扫描平台只说明该范围内不敏感，不能单独证明另一因素为唯一瓶颈；联合加密明确标为联合实验。
- 基与矩阵：对精确结构先给出理由，如正权 Gram 矩阵应正定；核对计算中的对称性、正定性、已知零模、尺度及条件数范数。超过精度分辨率的条件估计标为未分辨。
- 扰动：区分精确积分误差、两种实现的差异、求解残差和场误差；保留 E_N/e_N 的定义。残差小不等于 PDE 误差小。
- 时间：保持空间问题相同后比较步长；检查半离散算子与方法稳定域。RK4 是显式四阶方法，不假定无条件稳定。时间步长缩小未修复，不据此断言所有原因唯一确定。
- 物理：核对守恒、符号、单位及应有的范围；完整模型出现异常浓度，应报告并定位，不能用执行成功覆盖。

守恒、常数保持、非负性和解误差是不同检查。模型确实允许常数示踪解时，将该场代入连续方程及离散装配，分别检查残量；整体守恒通过不能代替常数保持通过。区域平均涉及多套求积时，核对测度、裁切、归一化和源/目标积分的一致性，再独立加密；不能仅凭二者差异就认定最终误差的唯一原因。

常数解未保持、流动背景与输运耦合失配、或有限源区域有多套积分时，读取 [常数保持与流动—输运一致性诊断](references/constant-balance.md)，按物理项拆解求解前残量。

每个假设说明证据和一个最小区分实验，一次只改变能归因的因素。记录未排除的原因。精度、基坐标、滤波、源核或均值条件的改变必须显式说明；它们可能改变比较对象。

交付：失败发生位置、关键公式/矩阵、诊断数据、支持的解释、待查问题和下一步。绘图调用 research-figures；新增正式算例由 numerical-experiment 管理。

涉及谱/PDE 收敛、范数对象、映射或误差预算时读取 [PDE 误差审查](references/pde-error-audit.md)，特别区分总场与剩余场的相对误差分母、参考误差及展示量。
