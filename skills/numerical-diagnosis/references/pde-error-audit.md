# PDE 与谱方法数值结论审查

只在需要评估 PDE、Galerkin、谱方法的误差、求积、时间推进或稳定性时读取。它是决策清单，不规定特定方程、求积阶数或软件后端。

## 1. 先确定比较的数学对象

- 从原始物理场、定义域、测度、范数及相对误差分母写起，再利用共同项抵消。若总场由奇异部分与正则部分组成，两个计算共享同一奇异部分时，误差分子可以抵消；总场相对误差的分母仍须使用总场。正则部分的相对误差应另行命名。
- 说明参考对象是真实解、制造解、加密数值解还是有限维参考解。共同网格上的采样差、连续函数范数、系数范数、两网格差与真实误差不是同一种量。可解析计算的质量或刚度二次型优先用于连续函数范数；无法解析的积分可用经独立加密核验的数值求积，并披露其误差地位。
- 坐标映射后逐项核对定义域、面积元、梯度、速度、源强度和边界条件；不要只因公式外观相似就沿用平面表达。
- 模型带单位或做维度约化时，列出输入、系数、测度和输出的单位，明确每次单位转换发生在哪一层；量纲一致仍需检查数量级与假设适用范围。

## 2. 按层建立误差预算

列明本次只改变哪一项，并分别检查：模型与边界假设、有限参考解、空间截断、时间离散、数值求积或混叠、代数求解、浮点误差、绘图采样。一个层面的高精度不能替另一层背书；小线性残差不证明装配精确，一种时间法的稳定性不证明空间求积可靠。

做收敛实验时固定物理输入和其余数值设置，分别改变谱截断、时间步长与求积规则。参考解也要检查尾部、求积和时间敏感性；若其中任一项与被测谱误差同量级，不把参考解称为已验证的精确解或误差上界。

## 3. 针对局部结构设计验证

- 有有限核、尖峰、界面或分段光滑项时，先比较其空间尺度与求积节点的覆盖情况。全域节点数增加不保证局部被积函数得到解析；需要时试验源区或界面适配积分，但必须同时检查分区过渡和剩余积分。
- 数值积分的替代公式必须独立核对符号、边界项、尺度因子及积分区域。局部修正若只改善一个载荷，不得宣称完整耦合算子或最终解已经精确。
- 制造解测试须包括非平凡的时间步和算子作用，避免初猜已等于答案导致迭代器未被真正测试。参考实现应尽量独立于待验证路径，辅以低阶可手算或对称性检查。
- 大规模计算记录尺寸、峰值内存、时间、容差与输出内容；局部数组按块计算，并与小规模未分块实现核对。内存优化不能改变数学公式。

## 4. 控制结论的强度

有限个截断上的代数或指数拟合只描述该测试范围。声称谱收敛速度前检查解与有限核的正则性、参考解独立性、求积和时间误差；既不因方法名为“谱”就预设指数收敛，也不因低阶拟合就断言只是一二阶。

谱半径小于 1 只支持固定离散系统的渐近模态判断；非正规系统仍可能短时放大。需要逐步能量估计时检查相应范数下的传播算子或 Hermitian 部分，并说明结论是否对截断阶数一致。

报告时依次写出：观察到的事实、可支持的有限结论、尚未排除的替代解释、下一项能区分这些解释的实验。图例与图注必须准确指明纵轴是什么，不能把两网格差、拟合曲线或系数尾部写作真实解误差或理论证明。

绘图若采用平滑、有限区域平均、插值或独立色阶，应保留原始数据和变换参数，在图注中区分原始解与展示量；“图像尖峰减少”不能代替算子、方程或原始解的验证。
