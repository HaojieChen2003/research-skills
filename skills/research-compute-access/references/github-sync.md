# GitHub 与跨设备同步

GitHub连接器、Mac Git和Windows Git是不同认证环境，分别检查权限、工具与工作副本，不能从一处成功推断另一处已配置。不要在文档写入历史探测状态作为当前事实。

记录移除凭据的remote URL、分支、commit、未提交文件及必要哈希。git clone不能复现未提交代码。使用现有认证机制，不将token、密码、私钥或含凭据URL写入文件/日志。

新项目记录本地/远端根目录、解释器、代码来源、输入/参数位置、同步与排除清单、输出目录。Git不可用时，授权范围内可以使用SFTP/SCP，不需要先修改整机环境。发布、强推、停止任务等行为遵循具体用户授权。
